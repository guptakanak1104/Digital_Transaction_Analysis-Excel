Digital Transactions Analysis Dashboard

An interactive Excel dashboard analyzing UPI digital transaction data, user demographics, banking performance, and fraud risk metrics.

📊 Dataset Key Fields

Transaction Info: Transaction_ID, Transaction_Date, UPI_App, Payment_Mode

Demographics: Age_Group, Gender, State, City

Merchant Details: Merchant_Name, Merchant_Category

Financials: Amount_INR, Cashback_INR, Transaction_Fee_INR

Banking & Risk: Bank_Name, Status, Failure_Reason, Device_OS, Risk_Score, Is_Suspected_Fraud

💡 Key Analysis & Insights

Volume & Category Trends: Tracks transaction totals across apps (PhonePe, Paytm, Google Pay) and categories.

Demographic Breakdown: User distribution by age, gender, and region.

Bank Performance: Analyzes transaction success/failure rates and failure causes.

Fraud & Risk Monitoring: Identifies high risk scores and flags suspected fraud cases.
